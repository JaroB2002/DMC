# DEFROST

An interactive Mariah Carey Christmas website for the annual **defrosting** meme — break the ice, watch the thaw, and follow the seasonal ritual from Halloween to Christmas Day.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Fan-made tribute. Original art and procedural sound only — no official affiliation and no copyrighted song audio.
